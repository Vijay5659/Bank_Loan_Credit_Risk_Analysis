Bank Loan & Credit Risk Analysis

Project Overview
This project analyzes bank loan data to understand loan distribution and default patterns using SQL Server and Power BI.

Tools & Technologies
- SQL Server: Data cleaning, SQL queries, and data analysis.
- Power BI: Interactive dashboards, KPI cards, slicers, and visualizations.

Dataset
-Source: Kaggle — German Credit Risk Dataset
- Total Records: 1,000
- Target Column: `default`
- `0` — Non-defaulted loan
- `1` — Defaulted loan

Dashboard Features
- KPI cards for Total Loans, Defaulted Loans, and Non-Default Loans.
- Interactive slicers for Credit History, Employment Duration, and Loan Purpose.
- Five charts analyzing loan distribution and default patterns.
- A separate Key Insights page with navigation buttons.

Key Findings
- Total loans analyzed: **1,000**
- Defaulted loans: **300**
- Non-defaulted loans: **700**
- Overall default rate: **30%**
- The employment category with less than one year of experience had a 40.70% default rate in the analysis.
- Furniture/Appliances was the most common loan purpose, with 473 loans.

Project Files
- `Bank_Loan_Credit_Risk_Analysis.pbix` — Power BI report
- `Bank_Loan_Credit_Risk_Analysis.sql` — SQL queries
- `Bank_Loan_Credit_Risk_Analysis_Report.docx` — Project documentation

## Conclusion
This project demonstrates how SQL Server and Power BI can be used together to transform loan data into useful visual insights for credit-risk analysis.
