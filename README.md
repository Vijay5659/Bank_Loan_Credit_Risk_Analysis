# Bank Loan & Credit Risk Analysis

## Project Overview
This project analyzes bank loan data using SQL Server and Power BI to understand loan distribution and default patterns.

## Tools & Technologies
- **SQL Server:** Data cleaning, SQL queries, and data analysis.
- **Power BI:** Interactive dashboards, KPI cards, slicers, and charts.

## Dataset
- **Source:** Kaggle — German Credit Risk Dataset
- **Total Records:** 1,000
- **Target Column:** `default`
- `0` — Non-defaulted loan
- `1` — Defaulted loan

## Dashboard Features
- KPI cards showing total, defaulted, and non-defaulted loans.
- Interactive slicers for credit history, employment duration, and loan purpose.
- Five charts for analyzing loan distribution and default patterns.
- A separate Key Insights page with navigation buttons.

## Key Findings
- **Total Loans:** 1,000
- **Defaulted Loans:** 300
- **Non-Defaulted Loans:** 700
- **Overall Default Rate:** 30%
- The less-than-one-year employment category had a 40.70% default rate.
- Furniture/Appliances was the most common loan purpose, with 473 loans.

## Project Files
- `Bank_Loan_Credit_Risk_Analysis.pbix` — Power BI dashboard
- `Bank_Loan_Credit_Risk_Analysis.sql` — SQL queries
- `Bank_Loan_Credit_Risk_Analysis_Report.docx` — Project report

## Conclusion
This project demonstrates how SQL Server and Power BI can transform loan data into useful visual insights for credit-risk analysis.
